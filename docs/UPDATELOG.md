# CoasterLab 업데이트 내역

## 2026-10-27

### 새로 만든 것

- Vite + TypeScript + Three.js 기반의 정적 웹 앱을 처음부터 구성했습니다. 서버, 로그인, 실행 중 AI 호출은 없습니다.
- Catmull-Rom 스플라인 트랙과 호 길이 계산, 곡률과 안정적인 트랙 좌표계를 구현했습니다.
- 위치에너지, 운동에너지, 마찰열, 수직항력, G-force를 계산하는 1차원 에너지 시뮬레이션을 구현했습니다.
- 2D 측면 설계 화면에서 제어점을 마우스·터치로 끌거나, Tab과 화살표 키로 옮기고, x·y·z 숫자로 수정할 수 있습니다.
- 3D 주행 화면에 트랙, 레일, 지지대, 카트, 출발 지점 표시, 그림자, 추적·궤도·측면 카메라를 넣었습니다.
- 힘 화살표(중력·수직항력·속도)와 편안한 카메라, 동작 줄이기 설정을 추가했습니다.
- 에너지·속도·G-force 그래프와 현재 주행 위치 표시, 접근 가능한 데이터 표를 추가했습니다.
- 5개의 미션(에너지, 마찰, 원운동, G-force, 안전)과 예측 고르기, 주행, 정답 확인, 해설, 점수 저장 흐름을 만들었습니다.
- 교사용 화면에서 미션 켜기/끄기, 정답과 해설 보기, 진도 초기화, 워크시트 인쇄, 투사용 그래프 라벨과 힘 화살표 설정을 할 수 있습니다.
- 진행 상황과 트랙, 설정을 브라우저 localStorage에 저장하고, 교사용 화면에서 초기화할 수 있게 했습니다.
- 데스크톱·태블릿·휴대폰 레이아웃과 모바일 실행 바, 그래프 탭을 넣었습니다.
- PWA 설치 아이콘, 매니페스트, 서비스 워커를 추가해 첫 방문 뒤 오프라인에서도 열립니다.
- 키보드 포커스, 대체 텍스트, 데이터 표, ARIA 역할, 색 대비를 점검해 axe 검사에서 심각한 문제가 없도록 했습니다.

### 검증

- 물리·스플라인·검증 단위 테스트 22개가 통과합니다.
- 브라우저 상호작용 테스트 11개가 통과합니다. 트랙 실행, 그래프 갱신, 제어점 드래그·키보드 이동, 미션 정답/오답, 교사용 초기화, 설정 유지, 인쇄, 모바일 화면, 접근성 검사를 포함합니다.
- 프로덕션 빌드와 첫 방문 후 오프라인 새로고침을 확인했습니다.
- 에너지 보존, 마찰열, 자유낙하 속도, 루프 꼭대기 G-force 공식을 해석적 기대값과 비교했습니다.

### 알아두기

- 화면에 표시되는 물리 결과는 공기저항과 바퀴 회전 관성을 넣지 않은 교육용 이상화 모델입니다. 실제 놀이기구의 안전 인증 자료가 아닙니다.
- 실행 방법: `npm install` 후 `npm run dev` (개발), `npm run build` (정적 빌드), `npm test` (단위 테스트), `npm run test:e2e` (브라우저 테스트).
